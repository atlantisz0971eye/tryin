# Tryin'

> 灵感来自 James Blake《Trying Times》、《星际穿越》、闵可夫斯基时空与"仙女座悖论"。界面版式借鉴了这张专辑的封面：整个页面是一张相纸，深色边框、下方两角各一行小写衬线字；点右下角会把相纸翻到背面，背面用铅笔手写着参数。

上传任意一张照片（或一段短视频），把那一瞬间凝固成一个可以走进去的粒子空间。

不用 AI 补全看不见的部分。照片里没有记录到的地方，就让它保持缺失，只是给它一个形状：
拍照那一刻，相机就像一道闪光，站在前面的人和物挡住了身后的世界，在背景上留下一块焦黑的"影子"；
前景和背景之间的空隙里，悬停着凝固的灰烬。

- **站在拍摄点**：看到的就是原照片，一切都对得上。
- **往旁边走**：前后景开始错开，被挡住的影子和灰烬露出来。
- **走进去**：就站在那一瞬间的里面。

## 视频：用位置重塑时间

传统影像用"每秒多少帧"来重塑一段时间。这里换一种方式：**用观看者在空间里的位置来决定看到哪个时刻。**
上传一段短视频（取前 10 秒，镜头尽量别动），每一帧都变成同一张像素网格上的粒子，每个粒子按你和它的位置关系各自选择显示哪一帧。

### 视频先稳像，再建时间场

时间场的前提是"同一个像素 = 同一条视线"，也就是机位固定。手持或摇镜头的视频不满足，背景上的同一栋楼在不同帧里落在不同的像素上，一走开就重影、错位。所以抽帧之后先做三件事：

1. **稳像**：用直接图像对齐估计每一帧相对中间那帧的相机旋转（横摇、俯仰、翻滚），用鲁棒损失忽略行人和车辆，再把所有帧重采样到同一个相机里。旋转相机看到的画面和深度无关，所以只需要旋转就够。
2. **静止背景的深度保持不动**：对每个像素，找出它"看起来是老样子"的帧，这些帧统一用中位深度；有东西经过的帧才保留各自的深度。
3. **"别处时刻"取第 3 远**，而不是最远，单帧的深度噪声不再会把它推远。

另外，某个像素的深度在两帧之间跳变（有东西从这里经过）时，不再对深度做线性插值，避免在人和背景之间出现悬空的点。

### 静止世界 + 演员层（默认的"清晰网格"画面）

固定机位的视频里，大部分像素从头到尾都不动。把画面拆成两层：

- **静止世界**：每个像素取"看起来是老样子"的那些帧的平均色，得到一张干净的底片（噪声被平均掉，路人经过的地方露出被挡住的背景），再配上稳定的深度。它和照片一样变成一张清晰的贴图网格，和时间无关，所以不会"飘"。
- **演员**：每帧与底片比较得到"动了的东西"的蒙版（强差异为核心、弱差异只在核心附近成立、去掉小斑点、外扩两个像素再羽化），整人整车作为一块带深度的贴图网格显示。

时间只决定演员此刻在哪个瞬间，而且是**按位置**而不是按像素选择：用模糊后的背景深度算出每个顶点的帧号，所以一个人始终是完整的一个人。演员边缘和背景之间的深度跳变处会丢掉细长的拉伸三角形，被拉得太开的部分会化成颗粒（与照片相同的"拉伸容忍度"）。

背面菜单里"画面"可以切回逐像素各走各的"粒子"，它仍然保留。

### 相对同时性：怎么走，此刻就怎么倾斜

依据是狭义相对论的**相对同时性**（参见彭罗斯的"仙女座悖论"）：运动中的观察者，认为"同时"的事件构成一张倾斜的切片。
这里把世界的光速调慢到每秒几米，让这件事肉眼可见：

```
T(p) = T₀                     你所在位置的此刻（世界线）
     + γ · (v · r) / c²       同时性倾斜：由你的速度决定
     − |r| / c                 光行时间：越远看到的越是过去（可选）
```

- **站着不动**：所有粒子处在同一个此刻，画面是完整的一帧。
- **动起来**：运动方向前方的世界进入未来、后方退回过去，越远偏得越多；停下后切片慢慢回正。
- **此刻怎么前进**（默认"随步行累积"）：每走一米，你自己的此刻前进一点；站着不动，时间就凝固。
- **走到尽头**（默认"往返"）：走到片段末尾，时间平滑地往回流；也可以选"循环"或"停在尽头"。
- **时差色调**：处在未来的粒子偏蓝、处在过去的偏红，对应多普勒效应里的蓝移和红移。
- **时空图**：相纸下边距正中的一个小小的闵可夫斯基简图：淡色的 ✕ 是光锥，金色的线是你此刻看到的"此刻线"（走动时会倾斜），小点是你，它的高度表示此刻在片段里走到了哪里。

**按场景深度自动校准**（默认开启）：不同场景尺度差别很大（房间几米、街景几十米），所以光速和步行比例会根据画面深度自动设定：

```
R = 场景深度中位数（不含天空）     L = 可走范围 ≈ 0.35 R（1–6 米）     D = 片长
同时性：  以步速 v 行走时，R 处偏移 D/4     →  c = √(v·R / (D/4))，且 v/c ≤ 0.7
光行时间：远处（第 90 百分位）在 0.8 D 内到达 →  c = R₉₀ / (0.8 D)
步行推进：在可走范围里走一个来回 ≈ 整段片子 →  每米 D / 2L 秒
```

步速先按设备估计（键盘约 1.2 m/s，触屏约 0.8 m/s），之后根据你实际走路的速度慢慢修正。手动拖动光速或步行比例会关闭自动校准。

时间预设：

| 预设 | 内容 |
|---|---|
| 同时性（默认）| 此刻 + 同时性倾斜 |
| 真实所见 | 此刻 + 同时性倾斜 + 光行时间 |
| 光速很慢 | 此刻 + 光行时间 |
| 以拍摄点为此刻 | 和原始视点相比，离得越近越是未来 |

**别处时刻**：在每个像素上，记下整段视频里"拍到过的最远表面"以及它是哪一刻拍到的。
当前时刻被前景挡住的地方，就显示那个真实存在过的别的时刻，并带一点冷色调；从来没被拍到过的地方仍然是黑的。不靠 AI 补全。

## UniverseChopLAb：把整段视频摊开成块宇宙

背面菜单（仅视频）里的 **UniverseChopLAb →** 进入一个全屏、宇宙风格的实验室。灵感来自"块宇宙"示意图：竖轴是时间，水平面是空间，整个宇宙历史已经固定在块里。块里的每一个点都是"某个像素在某个时刻的真实颜色"。

- **压成 2+1 维**：水平面是由深度重建出来的地面（左右、远近），竖轴是时间（往上是未来）；块外看时高度压成浮雕（真实高度的 15%）。
- **"现在"切片 = 真实的那一帧**：切片上是那一刻完整的视频画面（静止部分和动的部分都在），按深度立体排开；每个像素显示哪一帧由倾斜后的"现在"决定（t = T₀ + β·Δx / c），在 GPU 上逐像素选取。
- **恒星时空 = 静止层的时间柱**：静止世界里每个采样点是一根竖直的柱子，每一帧一个粒子，颜色就是这个点在那一帧的真实颜色。一根柱子就是一个点的全部历史，有人经过时那一段会变色。
- **地球时空 = 演员层**：动的部分逐帧往上叠成弯曲的世界管；离"现在"远的部分是幽灵，过去偏暖，未来偏冷。

两种视角对应两种时间观：

- **升起来看 = 钟表宇宙**：时间由宇宙外的一只钟推着走（可以用"钟在走"关掉）。摇杆上下拖动"现在"，左右给一个速度让切片倾斜（最高 0.75c），仙女座悖论：离得越远差得越多。
- **站到现在上 = 固有时**：回到人的尺度，站在拍摄点。"现在"在你四周是平的，倾斜只决定每个地方显示哪一刻；过去叠在脚下，未来叠在头顶。摇杆是真的在场景里行走，你的速度让"现在"倾斜；你活过的每一秒，视频走 γ 秒（速度越快，你的钟相对越慢）。手机上转动手机看（需要动作权限），电脑上拖动；W A S D 行走。
- 右上角的小圆点可以在实验室里录屏，Esc 退出。
- 主场景在实验室打开时暂停渲染，退出后原样恢复；数据全部来自已经算好的时间场，不需要重新估计深度。实验室会把深度和颜色帧再上传一份到 GPU（480p、40 帧约 40 MB）。

## 观看体验

- **近处柔焦**：点在屏幕上被放大后，会逐渐变成柔和的光斑。所有光斑先在半分辨率的缓冲里按颜色和权重累加，再归一化后叠到画面上，所以近处是一片平滑的柔焦，而不是一颗颗硬边的圆片。站在拍摄点时，点都很小，画面保持清晰。
- **沉浸背景**：把画面高度模糊后铺满四周，图像边缘的颜色向外延伸并逐渐变暗，类似 Vision Pro 看空间照片时的效果。视频模式下，背景会跟着当前此刻变化。
- **边缘融合**：画面靠近边缘的一圈（默认约 15%）会一边变模糊、一边变透明，画面本身化进背景光晕，而不是在边界上戛然而止。影子和灰烬在这一圈里逐渐变稀疏。宽度可以用"边缘融合"滑块调。

- **移动时自动正对画面**（默认开启，电脑和手机触屏）：视线会自动对准画面主体（原始视线上、距离为场景深度中位数的那一点），横着走就变成绕着那一刻转。你拖动视角产生的偏移会保留，只在移动时用约 1.5 秒缓缓回正；越接近对准点，自动对准越弱，穿过去时视线不会翻转。AR 里头部方向由观众自己决定，不做强制对准。

## 照片：清晰网格（默认）和粒子

照片模式有两种画面，背面的"surface"可以切换：

- **sharp photo mesh（默认）**：每个深度像素是一个网格顶点，颜色直接取**整张原图**当贴图，所以颜色分辨率不再受深度网格限制，近看也清晰。深度撕裂处的三角形会被去掉，撕裂依然是敞开的；撕裂边缘按"焦边场"碎裂并烧黑。影子和灰烬仍然是粒子。
- **particles**：原来的粒子画面。

网格从侧面看会把拍摄时几乎侧对着相机的那一小块图片拉得很开。着色器会比较"拍摄时这一块有多正对相机"和"你现在看它有多正对"，比值太大就把它溶解成颗粒，露出后面的影子。**stretch tolerance** 滑条控制容忍多少拉伸，越小颗粒越多。

**站在拍摄点，画面是干净的原照片。**轮廓边缘的碎裂、焦黑，以及藏在轮廓后面的影子和灰烬，都按视差出现：视线越偏离拍摄时的那条射线，它们越多。所以刚打开时看不到任何黑边，一走开，被挡住的地方才露出焦黑的影子，轮廓才开始碎成颗粒。

画面打开了抗锯齿（MSAA），网格的硬边不会有锯齿。

视频模式暂时仍然是粒子。

## 原理

| 层 | 内容 |
|---|---|
| 照片 | 每个像素按估计出的深度放到空间里，保留原色；轮廓边缘略微焦化（粒子模式；网格模式见上） |
| 影子 | 前景挡住的那块背景，只补几何（背景深度），不补内容，颜色焦黑 |
| 灰烬 | 沿着"相机 → 前景边缘 → 背景"的视线，撒稀疏的暗色粒子；影子体积里还有更淡的烟尘 |

深度估计用的是 [Depth Anything V2 Small](https://huggingface.co/onnx-community/depth-anything-v2-small)，通过 Transformers.js 直接在浏览器里运行（优先 WebGPU，不支持就用 CPU）。
**照片不会上传到任何服务器**，只有模型权重需要下载一次（约 20–50 MB），之后浏览器会缓存。

断裂检测是按行、按列扫描深度图：深度突变的地方就是"撕裂"，突变靠近相机的一侧是遮挡物，另一侧的深度就是它身后影子所在的深度。

## 本地运行

纯静态网页，不需要构建。用自带的开发服务器（禁用了缓存，改完代码刷新就能看到）：

```bash
python3 scripts/serve.py 5178
```

打开 http://127.0.0.1:5178 。也可以用 `?src=图片地址` 直接加载一张允许跨域访问的图片。

## 界面

整个页面是一张相纸：
- **正面**：画面在相纸里，左下角"回到原点"，右下角"tryin'"。
- **右下角**：把整张相纸翻到背面。背面写着全部参数和"换素材"按钮；左下角"翻回去"，右下角是镜像的名字，按 Esc 也能翻回去。
- 背面的字、滑条、勾选框、下拉框都是手绘的铅笔风格，像写在相纸背面一样。
- **开场页**：手写体，只有标题、一句话、一个手绘的输入框和一行小字。左右下角各画了一支手绘箭头，分别指向"回到原点"和菜单；菜单那支更大，会轻轻上下晃，右下角的 tryin' 也会呼吸并带下划线。第一次加载出画面后，这些提示会再出现 7 秒；翻过一次面之后就记住了，不再打扰。
- 下边距正中有一个抽拉小点：默认收起，点一下或往上拖，会从画面底部居中滑出距离、速度、此刻和操作提示；往下拖或再点一下收回。
- 最下方一行小字：灵感来源。
- **语言**：默认英文，背面右上角可以切换成中文，选择会记在浏览器里。

## 用手机走进去

iPhone 和安卓使用同一套代码，只用两边浏览器都有的能力，不需要摄像头：

- **转动手机就是转头**：用陀螺仪，手机就是一扇窗。
- **推摇杆就是移动**：画面下方中间的小图在触屏上同时是一根摇杆，从中心向上推前进、向下后退、左右侧移，推得越远越快，松手回中就停。
- 真实迈步计步（加速度计）仍保留，但因为不够准，默认关闭，在背面的"also count real steps"里打开。
- 素材加载完成后会出现邀请："Hold your phone up and look around"。点"look around"（iPhone 会弹出动作权限请求），此刻你面朝的方向就是照片拍摄时的方向。
- 左下角在走动时变成"re-center"：把你现在站的位置和朝向重新设为拍摄点。
- 走出这一瞬间能容纳的范围时，画面四周会变暗并提示转身。
- 背面可以开关"turn the phone to look"；打开计步后才有"walk scale"（行走比例）和"step length"（步长）。
- 走动时会保持屏幕常亮。

还没做：用摄像头做视觉追踪（6 自由度、能横着走、更精确）。

## 时间怎么随步行前进（按视频时长校准）

视频的步速和光速都由片长和场景深度推出来，而不是固定值：

- **每米推进多少秒**：由"时间密度"滑条决定。0 是真实时间（走一秒，视频走一秒）；1 是走完可走范围刚好播完整段视频一遍。默认 0.7，偏向铺满，但以步行速度算最快不超过 3 倍速。
- **光速 c**：让场景最远处的光约有片长的三分之一那么"老"，所以长短视频的相对论效果都读得出来。
- 手柄满推的速度是"约 4 秒走完可走范围"，可走范围由场景深度估计。

## 录屏

右上角的小圆点：点一下开始录，再点一下结束，手机弹出系统分享面板（可直接存到相册），电脑直接下载。只录画面，不录按钮，右下角带一个小小的 tryin' 水印。长边最大 1080，30 帧，最长 60 秒，全部在本机完成。iPhone 导出 mp4，Chrome 导出 webm（电脑端 Chrome 实测也是 mp4）。

## 操作

- 电脑：拖动看四周，WASD / 方向键 / 滚轮移动，Q E 升降，按住 Shift 加速
- 手机：单指拖动看四周，摇杆移动，双指张合前进后退，双指平移侧移
- 右下角翻到背面，可以调纵深、视场角、断裂阈值、灰烬密度、粒子大小，以及开关各层
